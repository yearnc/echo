# 回响 Echo

一个**单 App 双模式**的社交媒体模拟器。同一块屏幕，两个世界：

- **回响模式** —— 你发一条帖子，周围会临时聚起一群像真人的网民：有人只看、有人点赞、有人接梗。你也可以自己配置固定住民，让他们每帖都来、并记住你们聊过的事。**这里没有一个真实用户。**
- **清醒模式** —— 关掉所有虚拟反馈，只留客观分析（图片描述 / 情绪 / 逻辑 / 事实核查 / 改进建议）与价值重建练习（价值澄清、真实行动记录）。

做这个东西的动机很简单：**「被回应」的感觉是可以被制造的**，而人在多大程度上依赖它，往往要等到它消失时才看得清。这个 APP 想把这件事摆到台面上，让你亲手开关一次。

> 项目背景：思政实践课题《数字时代大学生自我价值感的异化与重建》，同时是一部微电影的核心道具。所以它对「拍摄」这件事有硬要求——见下面「三幕演示」。

## 快速开始

### 环境

开发时用的版本：Flutter stable（3.47.3）、JDK 17+、Android SDK（platform-tools / android-35 / build-tools）。

国内建议先配镜像，否则首次拉依赖会很慢：

```bash
export PUB_HOSTED_URL=https://pub.flutter-io.cn
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
```

### 离线语音模型（可选，但语音功能靠它）

住户的语音条用的是随包发布的离线**合成**模型，**模型文件不进仓库**
（几十兆的二进制会毁掉克隆体验）。不放也能跑：评论区全是文字，
语音条那个入口不出错、只是不出声。

放哪、下哪个，照目录里的说明做：

- `assets/models/tts/` —— 语音合成（AISHELL-3 多说话人，30 MB）

模型是 **Apache-2.0**，可以随应用分发；合成与播放全在本机，一个字都不上传。

> "按住说话"转文字在阶段 B 收尾时移除了：手机输入法自带这个能力，
> 为它多带 78 MB 的识别模型不划算。

### 跑起来

```bash
flutter pub get

# 数据库代码由 drift 生成；改过 lib/data/db/tables/ 下的表结构后必须重跑
dart run build_runner build

flutter run                 # 真机或模拟器
flutter run -d windows      # 桌面预览（手机尺寸窗口，需开启 Windows 开发人员模式）
```

> 桌面预览下语音**合成**能跑（Windows 用的是包里的 ONNX Runtime，
> 别被 `System32` 里那个旧版本抢了先，见 `lib/domain/services/speech_runtime.dart`），
> 但**播放**要 Android/iOS 才出声——桌面的音频输出靠平台插件，本项目没有接。

### 打包

```bash
# 按 ABI 拆包：每个架构一个 APK，真机装 arm64-v8a 那个就行
flutter build apk --release --split-per-abi
```

不拆的话，一个包里会带上 x86_64 / arm64-v8a / armeabi-v7a 三份原生库
（大头是 ONNX Runtime 与离线语音合成模型）。v3.0 的实测值：

| APK | 体积 |
|---|---|
| `app-arm64-v8a-release.apk`（真机） | **76.2 MB** |
| `app-armeabi-v7a-release.apk` | 65.9 MB |
| `app-x86_64-release.apk`（模拟器） | 81.3 MB |

注意 `--target-platform android-arm64` **不够**：它只管住 Flutter 自己的库，
插件带的 `.so` 照样三个 ABI 全进。给手机只用 `--split-per-abi` 产出的
`app-arm64-v8a-release.apk`。

体积的大头是随包发布的离线语音模型（约 30 MB）与 ONNX Runtime；
这两样是语音功能本身，拆不掉。放不下模型时应用照样能跑，评论区只是纯文字。

### 测试

```bash
flutter test        # 单元测试
flutter analyze     # 静态分析应当零问题
```

## 三幕演示（微视频拍摄）

拍摄**不需要任何特殊模式**，也不需要联网或真实模型——「策划模式」把脚本变成排期表，让**一条真帖子**按脚本发生。

1. 打开设置 → **策划脚本**，确认两个内置脚本在（不在就点右上角的「重置内置脚本」）
2. 回到发布页，在「策划模式」一栏勾上**按脚本安排互动**，选一个脚本 —— 脚本的开局正文/配图会自动填进发布页
3. 按下发布，然后**不要再碰屏幕**

| 幕 | 怎么拍 | 会发生什么 |
|---|---|---|
| 第一幕 · 建立幻觉 | 脚本「第一幕 · 天空照」 | 第 1.2 秒设定开局赞数，住民陆续点赞、评论、一条语音条，热度爬到第 60 秒 |
| 第二幕 · 异化与崩溃 | 脚本「第二幕 · 深夜垃圾桶」 | 发「垃圾桶」照 → 点赞暴涨 + 那段荒谬千字长评 |
| 第三幕 · 觉醒与重构 | **不用脚本** | 在**清醒模式**发同一张天空照 → 零个自动回应（清醒模式不排期）→ 打开「分析」看五项客观分析 |

**策划模式只安排"这条帖子会收到什么回应"**：点赞、评论、设定计数。不切模式、不跳页面、不代替用户点任何按钮——所以「切到清醒模式」「打开价值澄清」「打开真实行动」这几步要在拍摄时**手动完成**。

这不是将就：觉醒那个动作如果是脚本代劳的，它也就成了演的，而片子要戳破的恰恰是这个。

第三幕因此不需要脚本：它要的"一个回应都没有"，在清醒模式里本来就是默认状态。原先那个第三幕脚本已经下线（它唯一的动作是写一条客观分析，而分析页并不读它）。

脚本里的时间点可以在脚本管理页里改（`at` 写秒数如 `"30"`，或区间如 `"30~90"` 表示在这段时间里随机取一个时刻）。

**拍摄注意**：合规元素照常显示（回响模式底部「内容由AI生成，仅供参考」、清醒模式的永久提示）。这两处**不能为了画面干净而演掉**——它们本身就是这个作品要说的话之一。

## 配置模型（可选）

阶段 A 的演示与策划模式**完全离线**，不需要任何 API Key。只有「测试连接」和清醒模式的真实分析会用到模型。

设置 → **模型配置中心** → 新建，选一家服务商预设（DeepSeek / 通义千问 / 智谱 / Kimi / 豆包 / 硅基流动 / 混元 / 文心 / MiniMax / OpenAI）或「自定义（OpenAI 兼容）」，填 Key 后点测试连接。

- 密钥存在**系统钥匙串**（Android Keystore / iOS Keychain / Windows 凭据管理器），不写进数据库、不进代码
- 调用第三方模型时，帖内容会发送给你配置的那个 API —— 设置页与隐私说明里都有明示
- 其余所有数据只存在本机

## 项目结构

```
lib/
├─ app.dart            应用根组件 + 前台心跳
├─ core/               常量与合规文案、调色板与主题、路由、工具
├─ domain/
│  ├─ models/          Post / AiPersona / PostVoice / CustomResident /
│  │                    ResidentMemory / PostUnderstanding / PlanScript …
│  └─ services/        调度器、围观（AudienceService）、帖子解析、记忆、
│                       模式状态机、策划排期、防沉迷判定、外观
├─ data/
│  ├─ db/              Drift 表定义、迁移、播种（28 张表，schema v21）
│  ├─ repositories/    仓储实现（帖子 / 网民 / 记忆 / 固定住民 / 互动…）
│  ├─ media/           图片挑选与私有目录落盘
│  └─ seed/            内置脚本与素材清单的加载
└─ features/           按页面分组：feed / composer / post_detail / residents /
                       records / analysis / values / actions / safety /
                       stickers / scripts / models / settings /
                       onboarding / notifications
```

数据库共 28 张表（见 `lib/data/db/tables/`）：帖子、AI 住民、每帖网民快照、
互动队列、浏览记录、帖子解析、固定住民与长期记忆、评论、点赞、私信、
关系、通知、模型配置、策划脚本与事件、各类日志与真实行动记录。

## 合规与边界

这个项目刻意守着几条线：

- 回响模式所有页面底部固定「内容由AI生成，仅供参考」，数据层 `is_ai = true`
- 清醒模式的永久提示**不可关闭、不可删除**（界面上没有关闭按钮，代码里也没有删除入口）
- 防沉迷提醒**默认开启**，但只提醒、不拦截 —— 不锁屏、不劝退、不把使用时长变成需要打败的关卡
- 心理安全页提供求助入口（全国心理援助热线 12356，以官方最新公布为准）
- 情绪持续低落时，请找真实的人聊一聊。这个 APP 里的「网友」不能替代真实的对话
